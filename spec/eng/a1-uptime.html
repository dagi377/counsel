A1 Uptime: production architecture for 99.9% availability (Canada-only)

Targets: 99.9% monthly availability per cell (error budget 43 min 12 s per 30-day month), database RPO 0 for zone loss (quorum sync) and ≤ 5 min for region loss, document RPO ≤ 15 min for region loss (SLO-05b; trust/financial evidence RPO 0), RTO ≤ 60 min per cell and ≤ 4 h for all cells after region loss (SLO-06), all data in Canada. Shape follows Paploo ADR 0014 sec. 7 (one cell per firm, stamped from the Helm chart). Rules are ARC-U-###; each has a chaos test or drill. Machine-readable: a1-uptime.json.

Gap from Paploo today

  • deploy/helm/paploo: paplood replicas: 1; Postgres is one StatefulSet with no standby. HA needs ADR 0007 L12 (durable confirms/OAuth state) done first, then ≥ 2 replicas. River (ADR 0011) already gives multi-replica job locking.
  • Backups: daily encrypted CronJob (age), optional WAL shipping (backup.wal.enabled), off by default. Production needs WAL archive age ≤ 60 s to a DR-region bucket (ARC-U-008).
  • Cell stamping, fleet upgrades, per-cell backup/restore are ADR 0014 task A4 (not built).

4. Async, outbox and money

business tx (one DB transaction):
   UPDATE/INSERT domain rows
   INSERT outbox(id uuidv7, cell, topic, key, payload_json, idempotency_key, created_at, attempts=0)
relay (direct DB connection, not the transaction-mode pool):
   SELECT DISTINCT ON (subject) ... WHERE not delivered
     ORDER BY subject, subject_seq FOR UPDATE SKIP LOCKED LIMIT 100
   -- only the lowest undelivered seq per subject; n+1 waits for n
   call target with Idempotency-Key = outbox.idempotency_key, timeout, breaker
   2xx -> mark delivered | retryable -> next_attempt = now + rand(0, min(900s, 2s*2^n))
   money_external topic and age >= 20h -> GET provider by idempotency key/reference;
       found -> mark delivered | not found -> dead_letter + PAGE
   other topics: n >= 20 or age > 24h -> move to dead_letter, alert
consumer tx (inbox insert and effect in ONE transaction):
   INSERT inbox(message_id, consumer) ON CONFLICT DO NOTHING
   if inserted: apply effect (ledger row with UNIQUE(provider, provider_txn_id),
                one-per-source unique indexes, gate.effect_execution row)
delivery is at-least-once; the effect is exactly-once
